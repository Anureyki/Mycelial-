What happens when you ask it something

One question from the phone touches four layers and the guard. Nothing in this path knows horticulture except the agent that practises it.

Why it is shaped this way

Boss once held roughly 600 lines choosing between Grow's capabilities and 170 more writing horticulture prose. Every gap had one shape: a new ability was reachable from exactly one branch, and the question got phrased another way. "how long until it falls to 238" reached a code model and came back as a physics free-fall problem; DWC came back as "Direct Water Cooker".

Five verbs every agent inherits

All defined once in core/base_agent.py. A new domain agent becomes routable, answerable and narratable by starting up.

routing_terms Declares the words that claim a request for me. Replaced a keyword list inside Boss. Grow appends the names of the plants it is currently tracking, so registering a plant makes questions about it route from that moment.
answer I receive the prompt whole and pick my own capabilities. Replaced Boss's intent patterns and facet ordering.
ingest Anything recordable in the raw input, captured before anything slow runs. Grow recognises a reservoir reading stated in passing. Boss cannot — it does not know what a reading looks like.
describe I put my own result into words. Replaced 171 lines of Boss composing prose for domains it does not practise.
refer_finding
receive_finding Hand another domain something I noticed but do not own. Grow reads an equipment invoice; the spend goes to Accounting as a minimal payload. The default records it and says it only recorded it.

The rule that keeps them apart

Reference material is looked up by exact headword or citation, never by bag-of-words similarity — the CAG cache scores overlap with no stopword filter, so a long passage of boilerplate outranks a short passage that is exactly on point. Measured on a real case at 0.040 against 0.030.

Supervision is on demand, and narrow

Nothing runs on a timer. POST :8014/heal checks five core agents and restarts only the ones that are actually down.

Health is read from the port, never from the supervisor's own bookkeeping — it used to check only agents it believed were running, so one it had lost track of was never checked while one it wrongly believed alive was restarted forever. A restart is abandoned after three failures in ten minutes, with a reason and a log hint. Before that rule: ag_agent 484 restarts, quantum_agent 485, maintenance_agent 488.

Supervised: anansi · boss_agent · coding_agent · maintenance_agent · security_agent. Every other agent id is refused — an on-demand agent is not broken when it is down, it is off.

The four rules the shape comes from

Agents are the students Domain work goes to the domain agent. If it cannot do it yet, build the capability — that is the teaching. Substituting your own arithmetic leaves the agent exactly as capable as it was.
Lived data outranks documentation A label, a spec sheet, a statute as published is reference. What was measured is evidence. Where the two disagree the recorded outcome wins, and the disagreement is itself worth logging.
Hearing is not recording A fact spoken in conversation must reach the agent's record that turn, or it dies with the context. A 2-inch net-pot clearance was stated, agreed with, never written down — and two days later a volume measurement was analysed against the opposite assumption.
False success is the failure to hunt A command that reports success while doing nothing is worse than one that errors. Verify the effect, not the exit code. A check that found nothing must say so, distinctly from a check that found the thing to be fine.
